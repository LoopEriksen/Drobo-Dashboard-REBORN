# Reporting something privately

Issues on this repository are public. If you have found something you would
rather not post there -- a security problem in the app or the agent, or a
report whose diagnostics you cannot redact -- send it privately instead:
open this repository's **Security** tab and press **Report a vulnerability**
([direct link](https://github.com/LoopEriksen/Drobo-Dashboard-REBORN/security/advisories/new)).
Like an issue, it needs a free GitHub account. Describe what you did and
what happened, as the
[Tester report](https://github.com/LoopEriksen/Drobo-Dashboard-REBORN/issues/new?template=tester-report.yml)
form asks. Never include a password, the agent's access token or a packet
capture, even in a private report: a capture of this protocol can carry the
Drobo password in plain text, and none of them is needed.

What to expect: only you and the maintainer (and anyone the maintainer adds
to it) can see the report, and the maintainer replies there, privately.
